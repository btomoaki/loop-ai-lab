# General Feature Development Policy

## 🎯 Objective
This policy governs standard incremental feature development across all projects.

## 📋 General Rules
1. **Incremental Execution**: Implement features step-by-step with zero unnecessary code bloat.
2. **Quality & Test-Driven**: Every feature layer must be accompanied by unit tests or verification checks.
3. **Symbol Preservation**: Do not break existing exported APIs, function signatures, or data structures.
4. **Documentation**: Keep living README and architecture documentation up-to-date with code changes.
