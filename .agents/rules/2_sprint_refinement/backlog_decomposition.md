# 📝 Sprint Backlog Decomposition & DoR Rules

## 1. 🚥 DoR (Acceptance Criteria <= 2)
- Each task in `sprint_x_backlog.yaml` MUST have **at most 2 Acceptance Criteria**.
- If a task requires 3 or more criteria, it MUST be split into smaller single-responsibility tasks (`TASK-X.1`, `TASK-X.2`).
- Non-functional requirements (NFRs) are EXCLUDED from DoR and validated during DoD.
