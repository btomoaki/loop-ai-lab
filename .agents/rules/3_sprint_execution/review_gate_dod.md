# 🏁 Sprint Review Gate & DoD Rules

## 1. 🚫 No Ad-Hoc Design Changes Allowed
- During Sprint Review, ad-hoc architectural or API spec changes are STRICTLY FORBIDDEN to protect system consistency.
- Sprint Review is purely a DoD Pass/Fail gate (`sprint_x_harness.sh` 100% Pass, Clean Architecture, Security & Ethics).
- If fatal architectural flaws are discovered, execute a formal rollback to Refinement.
