# 1-Sprint-1-Task & Scope Inheritance Rule

## Rule Definition
1. **Single Task Mandate**: Each `sprint_N_backlog.yaml` MUST contain exactly ONE `task:` definition (NO `tasks:` arrays).
2. **Scope Inheritance**: Every `sprint_N_backlog.yaml` MUST inherit the parent `epic_scope` from `sprint_backlog.yaml` to preserve overall system architectural context.
