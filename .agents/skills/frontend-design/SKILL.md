# Modern Frontend Design & UI/UX Standards

Use this skill when building or styling web applications, UI components, and pages.

## 1. Aesthetic Excellence
- **Curated Color Palettes**: Avoid plain primary colors (plain red/blue/green). Use harmonious HSL dynamic color schemes, rich dark modes, or subtle gradients.
- **Modern Typography**: Use clean, modern sans-serif fonts (e.g. Inter, Roboto, Outfit) with intentional line-height and letter-spacing.
- **Visual Depth**: Utilize subtle drop-shadows, glassmorphism (`backdrop-filter: blur()`), and soft borders to create visual hierarchy.

## 2. Dynamic & Responsive Layouts
- **Responsive-First**: Design using CSS Grid and Flexbox to ensure seamless rendering across desktop, tablet, and mobile breakpoints.
- **Interactive Micro-Animations**: Add subtle transition effects on hover, focus, and click states (e.g. `transition: all 0.2s ease-in-out`).

## 3. Component Design Rules
- Keep UI components focused, decoupled, and reusable.
- Use explicit, semantic HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- Ensure all interactive elements have unique, descriptive `id` and `aria-label` attributes for accessibility and testing.
